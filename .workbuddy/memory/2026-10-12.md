# 2026-10-12

## 项目改名：aiface → AiCast（中文名「爱投屏」）

用户拍板两件事：包名一起改、工作区文件夹也改名。内容改名已完成，文件夹未能当场改（见下）。

### 改名映射（以后照此写，别再出现 aiface）

| 位置 | 旧 | 新 |
|---|---|---|
| Gradle 项目名 | `aiface` | `AiCast` |
| namespace / applicationId / 包名 | `com.aiface.app` | `com.aicast.app` |
| 源码目录 | `.../java/com/aiface/app/` | `.../java/com/aicast/app/` |
| 前台 Service | `AifaceService` | `AiCastService`（`BootReceiver` 仍在同一文件） |
| Compose 配色 | `aifaceColors()` | `aiCastColors()` |
| 主题 | `Theme.Aiface` | `Theme.AiCast` |
| 启动器名 / 通知标题 | `aiface` | `爱投屏` |
| JS SDK 资产 | `assets/aiface-sdk.js` | `assets/aicast-sdk.js` |
| JS 全局 / 桥 | `window.Aiface` / `AndroidAiface` | `window.AiCast` / `AndroidAiCast` |
| 页面事件名 | `aiface-message` | `aicast-message` |
| 页面 baseURL | `https://aiface.local` | `https://aicast.local` |
| mDNS 服务类型 | `_aiface._tcp` | `_aicast._tcp` |
| SharedPreferences | `aiface` `aiface_auth` `aiface_events` `aiface_params` | `aicast` 前缀同构 |
| log tag | `aiface` / `aiface-nsd` | `aicast` / `aicast-nsd` |
| CLI | `skill/bin/aiface` | `skill/bin/aicast` |
| CLI 存储目录 / 环境变量 | `~/.aiface` / `AIFACE_HOME` | `~/.aicast` / `AICAST_HOME` |
| Skill frontmatter | `name: aiface` | `name: aicast` |

`aiface` 与 `aicast` 都是 6 字符，DESIGN.md 里的 ASCII 架构图对齐**没有**被破坏；
只有换成「爱投屏」的地方会掉对齐，所以中文名只用在用户可见文案（启动器名、通知、
`acceptingHint` 引导语），代码标识符一律 `AiCast`/`aicast`。
